# Encapsulation in Dart

## Definition
Encapsulation = hiding internal data and controlling access using getters & setters.

- **Private variable** → `_variable`  
- **Getter** → read value  
- **Setter** → modify value safely  

---

## Real-Life Example: Bank Account

```dart
class BankAccount {
  double _balance = 0; // private variable

  // Setter-like methods
  void deposit(double amount) {
    if (amount > 0) {
      _balance += amount;
      print("Deposited: $amount");
    } else {
      print("Deposit must be positive!");
    }
  }

  void withdraw(double amount) {
    if (amount > 0 && amount <= _balance) {
      _balance -= amount;
      print("Withdrawn: $amount");
    } else {
      print("Invalid withdrawal!");
    }
  }

  // Getter
  double getBalance() {
    return _balance;
  }
}

void main() {
  BankAccount account = BankAccount();

  account.deposit(1000);         // Deposited: 1000
  account.withdraw(500);         // Withdrawn: 500
  print("Balance: ${account.getBalance()}"); // Balance: 500

  // account._balance = 100000; // ❌ Cannot access private variable directly
}
```

## Explanation
* _balance → hidden, cannot be accessed directly
* deposit() & withdraw() → safely change balance
* getBalance() → safely read balance
