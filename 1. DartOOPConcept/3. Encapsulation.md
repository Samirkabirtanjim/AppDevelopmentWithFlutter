# Encapsulation,getter,setter,async in Dart

## Definition
Encapsulation = hiding internal data and controlling access using getters & setters.

- **Private variable** → `_variable`  
- **Getter** → read value  
- **Setter** → modify value safely  

---

## Real-Life Example: Bank Account

```dart
class BankAccount {
  double _balance = 0; // private variable

  // Setter-like methods
  void deposit(double amount) {
    if (amount > 0) {
      _balance += amount;
      print("Deposited: $amount");
    } else {
      print("Deposit must be positive!");
    }
  }

  void withdraw(double amount) {
    if (amount > 0 && amount <= _balance) {
      _balance -= amount;
      print("Withdrawn: $amount");
    } else {
      print("Invalid withdrawal!");
    }
  }

  // Getter
  double getBalance() {
    return _balance;
  }
}

void main() {
  BankAccount account = BankAccount();

  account.deposit(1000);         // Deposited: 1000
  account.withdraw(500);         // Withdrawn: 500
  print("Balance: ${account.getBalance()}"); // Balance: 500

  // account._balance = 100000; // ❌ Cannot access private variable directly
}
```

## Explanation
* _balance → hidden, cannot be accessed directly
* deposit() & withdraw() → safely change balance
* getBalance() → safely read balance

## 🔷 1. Where the getter is used

```dart
double getBalance() {
  return _balance;
}
```

This is a getter because it reads the value of a private variable (_balance) safely.
Why we use it: We cannot access _balance directly outside the class, so getBalance() lets us see the balance.

Example usage:

print(account.getBalance()); // ✅ This is using the getter
## 🔷 2. Where the setter is used

In our class, deposit() and withdraw() act like setters:

```dart
void deposit(double amount) {
  if (amount > 0) {
    _balance += amount;
  }
}

void withdraw(double amount) {
  if (amount > 0 && amount <= _balance) {
    _balance -= amount;
  }
}
```

They change the value of _balance safely
Why we use it: We don’t want anyone to directly set _balance to a wrong value.

Example usage:

```sql
account.deposit(1000); // setter → safely increases balance
account.withdraw(500); // setter → safely decreases balance
```

## What is async?
async is a keyword in Dart used with a function.
It tells Dart: “This function will do something that might take time, and it won’t finish immediately.”
Usually used for waiting on tasks like:
Fetching data from the internet
Reading a file
Waiting for a timer

Important: async allows your program to not freeze while waiting.

## How it works
You mark a function as async:

```dart
Future<void> fetchData() async {
  print("Start fetching data...");
  await Future.delayed(Duration(seconds: 3));
  print("Data fetched!");
}
```

* await → Waits for a Future to complete inside an async function.
* Future → Represents a value that will be available later.

## Example

```dart
void main() async {
  print("Before fetching");
  await fetchData();
  print("After fetching");
}

Future<void> fetchData() async {
  print("Fetching data...");
  await Future.delayed(Duration(seconds: 2)); // simulate delay
  print("Data fetched!");
}
```

## Output:

```sql
Before fetching
Fetching data...
Data fetched!
After fetching
```

```sql
Notice how the program waits for fetchData() but doesn’t block other tasks if there were any.
```

## Why we use async:

* Avoid blocking the program – your app doesn’t freeze.
* Handle long-running tasks – network requests, file I/O, timers.
* Works perfectly with await and Future to write readable asynchronous code.
