# 🧠 Flutter Layout Alignment Cheat Sheet (Complete Guide)

This document explains **Row, Column, MainAxisAlignment, and CrossAxisAlignment** in Flutter in a simple and easy way.

---

# 📌 1. Core Concept

In Flutter, layout widgets like `Row` and `Column` always have two directions called **axes**:

## 👉 Main Axis
The direction where widgets are arranged.

## 👉 Cross Axis
The opposite direction of the main axis.

---

# 📦 2. COLUMN (Vertical Layout)

## 👉 Direction: Top → Bottom

Cross Axis (Left ↔ Right)
←────────────────────→

        ●
        ●
        ●   ↓ Main Axis (Vertical)
        ●

---

## 🧭 Column Axes

| Axis | Direction | Meaning |
|------|----------|--------|
| Main Axis | Top → Bottom | Vertical positioning |
| Cross Axis | Left → Right | Horizontal positioning |

---

## 🔥 Column Properties

### 👉 mainAxisAlignment (Vertical control)

Controls how widgets are placed top ↕ bottom:

MainAxisAlignment.start        → top  
MainAxisAlignment.center       → middle  
MainAxisAlignment.end          → bottom  
MainAxisAlignment.spaceBetween → first & last at edges  
MainAxisAlignment.spaceEvenly  → equal spacing everywhere  
MainAxisAlignment.spaceAround  → space around widgets  

---

### 👉 crossAxisAlignment (Horizontal control)

Controls how widgets are placed left ↔ right:

CrossAxisAlignment.start   → left  
CrossAxisAlignment.center  → center  
CrossAxisAlignment.end     → right  
CrossAxisAlignment.stretch → full width  

---

## 📌 Column Example

Column(
  mainAxisAlignment: MainAxisAlignment.center,
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    Text("Hello"),
    Text("Flutter"),
  ],
)

---

# 📦 3. ROW (Horizontal Layout)

## 👉 Direction: Left → Right

Main Axis →
●   ●   ●   ●   ●

↑
Cross Axis (Top ↕ Bottom)

---

## 🧭 Row Axes

| Axis | Direction | Meaning |
|------|----------|--------|
| Main Axis | Left → Right | Horizontal positioning |
| Cross Axis | Top → Bottom | Vertical positioning |

---

## 🔥 Row Properties

### 👉 mainAxisAlignment (Horizontal control)

Controls how widgets are placed left ↔ right:

MainAxisAlignment.start        → left  
MainAxisAlignment.center       → center  
MainAxisAlignment.end          → right  
MainAxisAlignment.spaceBetween → edges  
MainAxisAlignment.spaceEvenly  → equal spacing  
MainAxisAlignment.spaceAround  → space around widgets  

---

### 👉 crossAxisAlignment (Vertical control)

Controls how widgets are placed top ↕ bottom:

CrossAxisAlignment.start   → top  
CrossAxisAlignment.center  → middle  
CrossAxisAlignment.end     → bottom  
CrossAxisAlignment.stretch → full height  

---

## 📌 Row Example

Row(
  mainAxisAlignment: MainAxisAlignment.spaceEvenly,
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    Text("A"),
    Text("B"),
    Text("C"),
  ],
)

---

# ⚡ 4. Golden Rule

MAIN AXIS = direction of layout flow  
CROSS AXIS = opposite direction  

---

# 🧠 5. Easy Memory Trick

Column = Vertical (↑ ↓)  
Row = Horizontal (← →)

# 🚀 7. Real UI Example

Column(
  mainAxisAlignment: MainAxisAlignment.center,
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    Text(
      "Alex R. Thompson",
      style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold),
    ),

    Text("@alexrthompson | San Francisco"),

    SizedBox(height: 20),

    Row(
      mainAxisAlignment: MainAxisAlignment.spaceEvenly,
      children: [
        Text("Posts: 142"),
        Text("Followers: 1.8k"),
        Text("Following: 925"),
      ],
    ),
  ],
)

# 🧠 8. Final Understanding

Whenever you use Row or Column, always ask:

Which direction are my widgets flowing?

That direction is the MAIN axis.
